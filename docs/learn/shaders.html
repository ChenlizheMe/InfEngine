Writing shaders in Infernux

Keep ordinary GLSL for shader logic while Infernux generates bindings and stage interfaces. Start with materials, move into reusable lighting, and take full control only when the effect needs it.

In this chapterBeginner: Vert / FragIntermediate: ShadingModelAdvanced: custom stagesCommon errors

BeginnerVertex and fragment shaders

Start with the standard vertex path

The smallest mesh vertex shader only names the stage. With no vertex() hook, the engine applies its standard object-to-world-to-view-to-clip transform.

#version 450

ShaderInfo {
    Name "Standard"
}

Add the fixed hook when the mesh needs object-space deformation. VertexInput and _Globals are injected automatically.

ShaderInfo {
    Name "Wave"
}

void vertex(inout VertexInput v) {
    float wave = sin(v.position.x * 4.0 + _Globals._Time.x * 2.0) * 0.1;
    v.position.y += wave;
}

Describe a surface in the fragment stage

A regular material fragment shader fills SurfaceData. Its ShadingModel decides how that data becomes a final color.

#version 450

ShaderInfo {
    Name "Tinted Unlit"
    ShadingModel Unlit
    Queue 2000
    Properties {
        Color baseColor = [1.0, 1.0, 1.0, 1.0]
        Texture2D mainTexture = white
    }
}

void surface(out SurfaceData s) {
    s = InitSurfaceData();
    vec4 texel = texture(mainTexture, v_TexCoord);
    s.albedo = texel.rgb * v_Color * material.baseColor.rgb;
    s.alpha = texel.a * material.baseColor.a;
}

Common property types are Float, Float2, Float3, Float4, Color, Int, Mat4, and Texture2D. Add Range(min, max) for an Inspector range or HDR for an HDR color.

Properties {
    Float roughness = 0.5 Range(0.0, 1.0)
    Color emission = [0.0, 0.0, 0.0, 1.0] HDR
}

SurfaceData carries albedo, normalWS, metallic, smoothness, occlusion, emission, alpha, and specularHighlights.

Material state belongs in ShaderInfo

ShaderInfo {
    Name "Transparent Unlit"
    ShadingModel Unlit
    Queue 3000
    Cull Back
    DepthWrite Off
    DepthTest LessEqual
    Blend SrcAlpha OneMinusSrcAlpha
    CastShadows Off
    ReceiveShadows Off
}
Exact IDs matter.

A material selects a shader by its exact, case-sensitive Name. Queue also decides which RenderPipeline route consumes the material.

IntermediateReusable shading models

A surface shader answers “what is this surface?” A shading model answers “how does it interact with light?” This lets many materials share PBR, unlit, toon, halftone, or project-specific lighting.

ShadingModelInfo {
    Name "FlatTint"
    Entry Forward evaluateForward
}

void evaluateForward(in SurfaceData s, out vec4 color) {
    vec3 base = clamp(s.albedo, 0.0, 1.0);
    color = vec4(base + s.emission, s.alpha);
}

Reference it with ShadingModel FlatTint. A custom deferred encoding may also declare Entry GBuffer evaluateGBuffer. If a conventional surface model omits that entry, Infernux can use its standard PBR-oriented GBuffer encoding, keeping material code portable between Forward, Forward+, and Deferred routes.

AdvancedFully custom stages

Use a custom stage for procedural geometry, editor utilities, fullscreen effects, or specialized domain renderers that cannot be expressed through surface() and the standard vertex hook.

#version 450

ShaderInfo {
    Name "Color Invert"
    Capabilities [Fullscreen]
    Resources { Texture2D _SourceTex }
    Inputs { Float2 inUV }
    Outputs { Float4 outColor }
}

void main() {
    vec4 source = texture(_SourceTex, inUV);
    outColor = vec4(vec3(1.0) - source.rgb, source.a);
}

Use Capabilities [Standalone] when a geometry stage owns an explicit main(). Describe inter-stage values through Inputs and Outputs, textures through Resources, and small per-draw data through PushConstants.

Do not write manual layouts.

Authored layout(location=...), descriptor set/binding layouts, uniform blocks, and push-constant layouts conflict with the generated RHI interface. Describe them in ShaderInfo instead.

GoalStart here

Common errors

  • Missing fixed entry point: structured material stages need the expected vertex() or surface() hook.
  • Object disappears after a shader change: confirm that both stages belong to the material geometry domain and their IDs match exactly.
  • Transparent object renders opaque: inspect Queue, DepthWrite, and Blend together.
  • Duplicate layout diagnostics: remove authored layouts and describe the interface in ShaderInfo.

在 Infernux 中编写 Shader

Shader 逻辑继续使用普通 GLSL，绑定与阶段接口则由 Infernux 生成。先从普通材质入手，再进入可复用光照，只有确实需要时才完整接管 GPU 阶段。

入门普通 Vert 与 Frag

从标准顶点路径开始

最小的网格 Vert 只需要命名阶段。不提供 vertex() 时，引擎自动完成物体空间到世界、观察和裁剪空间的标准变换。

#version 450

ShaderInfo {
    Name "Standard"
}

需要在物体空间做顶点变形时，加入固定 Hook。VertexInput 与 _Globals 会自动注入。

ShaderInfo {
    Name "Wave"
}

void vertex(inout VertexInput v) {
    float wave = sin(v.position.x * 4.0 + _Globals._Time.x * 2.0) * 0.1;
    v.position.y += wave;
}

在片元阶段描述表面

普通材质的 Frag 负责填写 SurfaceData，最终如何结算颜色由 ShadingModel 决定。

#version 450

ShaderInfo {
    Name "Tinted Unlit"
    ShadingModel Unlit
    Queue 2000
    Properties {
        Color baseColor = [1.0, 1.0, 1.0, 1.0]
        Texture2D mainTexture = white
    }
}

void surface(out SurfaceData s) {
    s = InitSurfaceData();
    vec4 texel = texture(mainTexture, v_TexCoord);
    s.albedo = texel.rgb * v_Color * material.baseColor.rgb;
    s.alpha = texel.a * material.baseColor.a;
}

常用属性类型包括 Float、Float2、Float3、Float4、Color、Int、Mat4 和 Texture2D。用 Range(min, max) 声明 Inspector 范围，用 HDR 声明 HDR 颜色。

Properties {
    Float roughness = 0.5 Range(0.0, 1.0)
    Color emission = [0.0, 0.0, 0.0, 1.0] HDR
}

SurfaceData 提供 albedo、normalWS、metallic、smoothness、occlusion、emission、alpha 与 specularHighlights。

把材质状态写进 ShaderInfo

ShaderInfo {
    Name "Transparent Unlit"
    ShadingModel Unlit
    Queue 3000
    Cull Back
    DepthWrite Off
    DepthTest LessEqual
    Blend SrcAlpha OneMinusSrcAlpha
    CastShadows Off
    ReceiveShadows Off
}
ID 必须精确匹配。

材质通过区分大小写的 Name 选择 Shader。Queue 还会决定该材质由 RenderPipeline 的哪条 Route 消费。

进阶可复用的着色模型

Surface Shader 回答“表面是什么”，着色模型回答“表面如何与光照交互”。多个材质因此可以共享 PBR、Unlit、卡通、半调或项目自己的光照模型。

ShadingModelInfo {
    Name "FlatTint"
    Entry Forward evaluateForward
}

void evaluateForward(in SurfaceData s, out vec4 color) {
    vec3 base = clamp(s.albedo, 0.0, 1.0);
    color = vec4(base + s.emission, s.alpha);
}

Frag 通过 ShadingModel FlatTint 引用它。自定义 Deferred 编码时，还可声明 Entry GBuffer evaluateGBuffer。常规表面模型省略该入口时，引擎可以使用标准 PBR 型 GBuffer 编码，让材质代码在 Forward、Forward+ 与 Deferred Route 之间复用。

高级完全自定义流程

程序化几何、编辑器工具、全屏效果或专用域渲染器无法通过 surface() 与标准顶点 Hook 表达时，再使用自定义阶段。

#version 450

ShaderInfo {
    Name "Color Invert"
    Capabilities [Fullscreen]
    Resources { Texture2D _SourceTex }
    Inputs { Float2 inUV }
    Outputs { Float4 outColor }
}

void main() {
    vec4 source = texture(_SourceTex, inUV);
    outColor = vec4(vec3(1.0) - source.rgb, source.a);
}

几何阶段需要自己提供显式 main() 时，使用 Capabilities [Standalone]。跨阶段数据写入 Inputs 和 Outputs，纹理写入 Resources，少量逐 Draw 数据写入 PushConstants。

不要手写 Layout。

手写 layout(location=...)、描述符 set/binding、Uniform Block 或 Push Constant 布局会与生成的 RHI 接口冲突，应统一通过 ShaderInfo 描述。

选择足够完成目标的最低层级

目标使用方式
网格变形或顶点动画带 vertex() 的标准 Vert
定义材质外观带 surface() 的 Frag
复用一种光照风格.shadingmodel
编写全屏 PassCapabilities [Fullscreen]

常见错误

  • 缺少固定入口：结构化材质阶段需要对应的 vertex() 或 surface() Hook。
  • 切换 Shader 后物体消失：确认 Vert/Frag 都属于材质几何域，且 ID 大小写完全一致。
  • 透明物体仍按不透明渲染：一起检查 Queue、DepthWrite 与 Blend。
  • 布局重复：移除手写 Layout，改由 ShaderInfo 描述接口。
