Gameplay course

Build gameplay with Python

Build a playable loop with Infernux's component-oriented Python API, then expand it with input, physics, scenes, UI, prefabs, and coroutines.

8 chapters · Beginner to advanced

From a running component to a complete game loop

Each chapter adds one practical part to the same mental model: a GameObject owns components, components react to the engine lifecycle, and public fields connect authored scene data to runtime behavior. Particle graphs, skeletal animation, and the MCP automation tooling are planned follow-up topics outside this course.

Create and run your first component

Create a Python component, attach it to a GameObject, enter Play mode, and verify the lifecycle through the Console.

GameObjects, components, and authored fields

BasicsPythonEditor
03

Input, time, and movement

Read keyboard and mouse state, use delta time correctly, and move an object without frame-rate-dependent behavior.

BasicsPythonInput
04

Prefabs and runtime object lifetime

Instantiate authored objects, choose parent and world-space behavior, keep references, and destroy instances safely.

05

Physics and collision callbacks

06

UI actions and scene flow

Audio and gameplay signals

用 Python 实现游戏逻辑

使用 Infernux 面向组件的 Python API 搭起可玩的游戏循环，再逐步加入输入、物理、场景、UI、Prefab 与协程。

共 8 章 · 从入门到进阶

从第一个可运行组件到完整游戏循环

每一章都沿用同一套心智模型：GameObject 承载组件，组件响应引擎生命周期，公开字段把场景中的配置连接到运行时行为。粒子图、骨骼动画与 MCP 自动化工具属于后续专题，暂未纳入本课程。
