CHECKPOINT · ONLINE
v0.3.4

Performance and architecture overhaul

  • A large-scale refactor across memory, serialization, editor interaction, physics and runtime ownership, and the Python/C++ boundary, with broad performance work throughout the engine.
  • Introduces the MCP Harness, expands Timeline and animation workflows, improves rendering throughput, and reduces release package size.
NEXT · TRANSIT
v0.4

Unified authoring and programmable rendering

  • Continue unifying editor interaction and the Player runtime, then expand deterministic MCP validation over public workflows.
  • Harden GPU Particle Graph and programmable rendering, then add Shader Graph on the shared node foundation.
MID-COURSE
v0.5

Particles, terrain, and content pipeline

  • A broader GPU particle library, terrain, and a deeper model, texture and material pipeline.
  • Expand the range of visual content the engine can produce without collapsing under content complexity.
SHIPPING TRAJECTORY
v0.6+

Networking and project lifecycle

  • Networking foundations and a more complete project lifecycle from prototype to release.
  • Move from Windows-first technical preview toward a multi-platform production engine.
Operations bands

The roadmap is split by what each band actually unlocks.

Each band answers one practical question: can teams author faster, can content scale, can projects ship, and can the architecture stay readable while the engine grows?

Authoring band

  • Animation state machines, Timeline, and rigged character workflows beyond the 0.3.4 foundation.
  • Advanced UI controls (ScrollView, Slider, layout groups).
  • Safer asset rename and dependency repair paths.

Content band

  • Broaden the GPU Particle Graph sample library, collision paths, profiling and debugging tools.
  • Terrain system for larger production scenes.
  • Better scene composition for reusable runtime content.

Shipping band

  • Networking foundations.
  • A more robust project lifecycle from prototype to release.

Architecture band

  • Keep render and tooling internals explicit as the engine grows.
  • Avoid accidental complexity that would erase the engine's main advantage.
  • Preserve scriptability while strengthening native ownership boundaries.
Immediate focus

What deserves attention in the next two milestones.

The next work turns the new rendering, graph, interaction and runtime foundations into one coherent production workflow.

Unified editor interaction

Continue the shared command, selection, document, save, conflict and undo/redo core across every authoring panel.

Particle Graph production pass

Harden GPU simulation, exposed parameters, collisions, profiling and a production-quality sample library.

Shader Graph and render authoring

Bring Shader Graph onto the shared node foundation and keep simplifying GLSL, shading models, effects and RenderStack authoring.
